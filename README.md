## 🌟 Featured Project: Antigravity Toddler Game

<div align="center">
  <h3>🎈 Floating Wonders (Ages 1–3)</h3>
  <p><b>A joyful, multi-touch sensory web game designed specifically for early childhood discovery.</b></p>
  
  <a href="https://game-kids-1-3.onrender.com/">
    <img src="https://img.shields.io/badge/▶_LAUNCH_LIVE_GAME-https%3A%2F%2Fgame--kids--1--3.onrender.com-blue?style=for-the-badge&logo=google-chrome&logoColor=white" alt="Play Game" height="40" />
  </a>
</div>

<br/>

### ✨ Highlights:
- 🎈 **Antigravity Motion**: Shapes float upwards with gentle sinusoidal floating physics.
- 🎯 **Toddler Hitboxes**: Extra +30px touch tolerance for clumsy little fingers.
- 🖐️ **Multi-Touch**: Supports two-handed screen tapping without lag or accidental browser zoom.
- 🎶 **Soothing Synthesizer**: Native Web Audio API plays harmonic C-Major pentatonic notes that never clash.
- 🚀 **Powered by Go**: Lightweight, high-concurrency Go backend running seamlessly on Render.
